Aivox Help & Compatibility

Aivox offers manual call recording only on explicitly validated device and firmware configurations. The current MVP capture configuration is Samsung SM-A266B, Android API 36, with the exact validated firmware shown by the app's compatibility check. Other devices, Android versions, and firmware cannot start capture. Aivox does not record automatically.

Set up on a supported phone

  1. Read and accept the in-app disclosure, including the recording-consent responsibility.
  2. Voluntarily enable Android Developer options and Wireless Debugging. Open Android's pairing-code dialog and keep it visible.
  3. Use Aivox's pairing notification or in-app pairing field to enter the code locally. Never send the code to support.
  4. Return to Aivox and tap Activate helper. Aivox checks the validated configuration and the fixed-purpose shell helper before enabling Start recording.

PAIRING REQUIRED means Aivox has no completed local pairing; repeat the pairing steps. REACTIVATION REQUIRED means the saved pairing remains but the helper is unavailable; tap Activate helper again. Android may require setup again after reboot, a helper stop, or revoked Wireless Debugging authorization.

Record and manage files

When Aivox reports Ready on a validated configuration, tap Start recording manually, then tap Stop recording to finalize the file. Follow applicable recording-consent laws. The local Recordings library lists completed files with date and duration. Select a file to play, pause, resume, or seek. Export copy opens Android's system save interface; you choose the destination. Delete recording asks for confirmation before removing the local file.

Unsupported devices

If the app reports unsupported configuration, Start remains unavailable and the helper cannot be activated. Existing local recordings can still be viewed, played, exported, and deleted. A pairing-required status can still appear because this device has no Aivox pairing; it does not imply capture support.
